# Audit Report: Dictionary Program

## 1. Program Details

* **File Name:** `dictionary.py`
* **Language:** Python
* **Purpose:** Demonstrate how to create and access a Python dictionary.

## 2. Concepts Reviewed

* Dictionary creation.
* Key-value pairs.
* Accessing values using keys.
* Variables.
* Output using `print()`.

## 3. Code Review

The program creates a dictionary named `student` containing the keys `name`, `age`, and `marks`.

It displays the complete dictionary and accesses individual values using their corresponding keys.

## 4. Expected Behaviour

The program should display the dictionary containing the predefined student information and print the student's name and age.

## 5. Limitations

* The student information is predefined in the code.
* The program does not accept student information from the user.
* Runtime testing has not been performed.

## 6. Recommendations

* Test dictionary access using the predefined keys.
* Consider adding more student attributes.
* Explore how to add, update, and remove dictionary entries.

## 7. Audit Conclusion

The program demonstrates the basic use of Python dictionaries and key-value pairs.

**Audit Status:** Code reviewed; runtime testing pending.
